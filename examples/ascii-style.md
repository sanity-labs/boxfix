# ASCII Style Boxes

Classic ASCII art using `+`, `-`, and `|` characters instead of Unicode box-drawing.

```
+------------------------+
| Database Connection    |
| Host: localhost        |
| Port: 5432             |
+------------------------+
        |
        v
+------------------------+
| Connection Pool        |
| Max: 10                |
| Timeout: 30s           |
+------------------------+
```

Content lines are padded to match the 26-character boundary width. Works the same as Unicode boxes.
